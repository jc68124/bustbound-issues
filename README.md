# Bustbound — Issues & Feedback

The public home for Bustbound bug reports and feature requests.

Found something that isn't working, or have an idea to improve the game? Open an issue using one of the templates in the **Issues** tab.

## Report a bug

Tell us what happened, what you expected, and how we can reproduce it. Your device, browser, and screenshots can help us work out what went wrong.

If you can't reproduce the problem, describe what you were doing when it happened.

## Suggest a feature

Describe your idea and how it would improve the experience for players. Suggestions for gameplay, usability, and accessibility are all welcome.

## Before opening an issue

- Search existing issues to see whether someone has already reported the same thing.
- If there's a matching issue, add any useful details there.
- Keep each issue focused on one bug or suggestion.

## About this repository

This repository is for feedback and issue tracking. Bustbound's source code is maintained separately in a private repository.

Thanks for helping improve Bustbound!
